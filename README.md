# Maglev High Capacity Wagons

An OpenTTD NewGRF providing nine high-capacity, fast-loading Maglev wagons.

## Wagon types

Passengers, Steel, Armoured (Valuables), Oil, Coal, Livestock, Grain, Goods and Iron Ore.

Each wagon is designed for 1,000 cargo units, with loading speed 255 and introduction year 2020. Wagon speed is set to 0 km/h (no wagon-imposed speed limit).

## Graphics

Nine cargo-specific, 32bpp pixel-art sprite sheets are generated by `tools/generate_sprites.py` using Pillow. The graphics distinguish passenger windows, oil tankers, coal and ore hoppers, steel loads, livestock ventilation, grain hoppers, goods containers and armoured valuables wagons.

Each sheet includes an 8bpp recolour mask using the OpenTTD/NML DOS palette and primary company-colour indices. The masked accent stripe is intended to follow the player's company colour. This feature still requires an in-game visual test.

**Graphics status:** Initial sprite implementation, not final polished isometric artwork. All eight directions currently use side-oriented drawings, so directional polish is planned.

## Build

Prerequisites: Python 3, NML and Pillow.

```sh
python -m pip install nml Pillow
python tools/generate_sprites.py
sh build.sh
```

The GitHub Actions workflow builds the NewGRF automatically and uploads `maglev_high_capacity_v0.1.0.grf` as an artifact.

## Install and test

Download the artifact ZIP from the latest successful GitHub Actions run. Extract the GRF into your OpenTTD `newgrf` directory, enable it in NewGRF Settings, and start a game in 2020 or later. Verify wagon cargo capacities, company-colour accents, sprite appearance, and full engine speed.

## Status

The NewGRF has compiled successfully in GitHub Actions. Graphics and recolouring need visual verification in-game before a polished release.

## Original OpenGFX artwork and licence

All nine wagons use the original indexed 8bpp wagon artwork from [OpenTTD/OpenGFX](https://github.com/OpenTTD/OpenGFX), file `sprites/png/trains/temperatemonolev.png`, using original `tmpl_train_4view_88length_28px` dimensions and offsets. This includes the original passenger, steel, valuables/armoured, oil, coal, livestock, grain, goods, and iron ore wagon appearances.
